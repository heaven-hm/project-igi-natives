Address: 0x0044E3F0
Signature: int AIFunction_GetAlarmTriggerID()

## Recovered behavior

RETURNS the id of the alarm trigger bound to this AI (see AIFunction_SetAlarmTriggerID). Takes no args. Use in handlers to check which alarm applies.
